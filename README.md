# English News Feed Recommendation System

本仓库用于构建一个面向英语新闻内容的个性化推荐系统，当前阶段提供整体方案与项目规划。随着研发推进，将逐步补充数据处理、模型训练、在线服务等模块的代码与文档。

## 背景
- 真实用户行为数据稀缺，点击事件小时级同步。
- 计划以 Mine 英语新闻数据集作为初始训练数据源。
- 框架尚未确定，正在评估 EasyRec 及其他开源方案。

## 项目目标
1. 建立可扩展的数据与特征管道，为新闻内容生成结构化特征和语义表示。
2. 设计多路召回和排序架构，支持冷启动场景，并能随用户行为回流逐步迭代。
3. 提供可部署的在线推荐 API，支持前端 Feed 请求、监控与 AB 测试。
4. 建立模型训练与评估流程，实现版本管理、线下指标评估与上线回滚。

## 阶段性规划
- **阶段一：原型验证**
  - 清洗 Mine 数据集、构建内容库与基础 embedding。
  - 搭建热门榜与内容相似度召回，完成初版排序模型（LR/GBDT）。
  - 建立离线训练与评估 pipeline。
- **阶段二：上线 MVP**
  - 搭建在线推荐服务，联通前端。实现小时级日志回流与批更新。
  - 上线监控、AB 测试能力，验证指标。
- **阶段三：迭代优化**
  - 引入协同过滤、多路召回与深度排序模型（DIN/DSSM）。
  - 加入重排、多目标优化和特征服务。
- **阶段四：扩展与智能化**
  - 引入强化学习、生成式摘要、多模态内容。
  - 完善解释性、审核与隐私合规方案。

详细方案请参阅 [PLAN.md](./PLAN.md)。
